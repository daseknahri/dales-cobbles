# Dales & Cobbles — "Soap Spoilers · News · Gossip"

UK soaps fan blog for **Emmerdale** (the Dales) and **Coronation Street** (the Cobbles), written
fan-to-fan for the owner's Facebook groups (~54K members). Served (in the next phase) at
**dalesandcobbles.getemoji.site**. WordPress on Docker (Coolify), fully set up on first start —
no wp-admin clicks needed. Cloned from the deutsche-rezepte / Oma Gerda (germ) repo and rebranded:
same self-seeding engine, article pillars instead of recipes, all recipe machinery removed.

## What's inside
- `wp-content/themes/viral-reader` — parent theme (vendored, v1.9.37, from plgin `main`)
- `wp-content/themes/dales-cobbles` — brand child theme (v1.0.0): self-hosted Anton (headlines)
  + Literata, BRAND.md tokens (Dales greens #14401F/#1E5631, gold #E9B44C, brick #A63A28, cream
  #FBF6EA, ink #1E221A, spoiler pink #FF4D8D sparing), category-coloured pillars,
  end-of-article share + "next article" flow, sticky next-article bar, dark mode
- `wp-content/plugins/automation-hamri` — publishing/SEO/ads engine (vendored, build-v9 9.48.0
  from plgin `main` — the released version; 9.48.1 exists only on the unmerged BL-010 branch)
- `wp-content/mu-plugins/dc-page-cache.php` — tiny full-page cache (per URL + phone/desktop key,
  30 min TTL, purge on publish; logged-in/commenters bypass). Header `X-DC-Cache: hit` on hits.
- `content/site-profile.json` — brand identity (name/tagline/email, writer, assets, locales,
  slugs, categories). The seed reads it for brand/categories; `seed/seed.php` holds the fallbacks.
- `content/images/` — committed raster brand assets (icon, logos, OG card, hero). Never hotlinked.
- `data/bundles/*.zip` — article bundles (posts.json + images) imported on first start; empty at
  launch until the first content batch lands.
- `seed/seed.php` — brand, en_GB locale, 5 categories, 7 trust pages, menus, stage-1 ads.txt,
  bundle import (idempotent, resumable). `DC_SEED_VERSION` 1.
- `docker/site-init.sh` — waits for DB, syncs theme/plugin, installs WP (en_GB) once, runs the seed.

## Coolify (next phase — owner approvals)
Docker Compose build pack, compose file `docker-compose.yml` ONLY, domain on the `wordpress`
service. Env vars:
- `SERVICE_FQDN_WORDPRESS_80` (the domain), `SERVICE_USER_MYSQL`, `SERVICE_PASSWORD_MYSQL`,
  `SERVICE_PASSWORD_MYSQLROOT`, `SERVICE_PASSWORD_WPADMIN` — generated by Coolify
- `SITE_URL` (default https://dalesandcobbles.getemoji.site), `SITE_EMAIL`, `WP_ADMIN_EMAIL`
- `ADSENSE_CLIENT` / `ADSENSE_PUB_ID` — default ca-pub-6869205417923902 / pub-6869205417923902
  (getemoji.site family publisher); `ADSENSE_ENABLE=0` at launch (stage 1: ads.txt served, no ads)
- `GA_ENABLE=0`, `HISTATS_ID` unset/off — analytics off until the owner creates the properties
- Google Site Kit — installed/activated by site-init.sh from wordpress.org; owner connects
  Analytics/AdSense in wp-admin. The theme blocks Site Kit's duplicate AdSense snippet.

Admin login: user `editor` (WP_ADMIN_USER), password = Coolify's `SERVICE_PASSWORD_WPADMIN`.

## Local QA
```
copy .env.example .env   (fill in fresh random passwords + salts — never a sibling's .env)
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build
# http://localhost:8096 — WP_ENVIRONMENT_TYPE=local applies only in this override
docker compose -f docker-compose.yml -f docker-compose.local.yml down   (volumes kept)
```

## Editorial rules (from BRAND.md)
Warm, northern, fan-to-fan. Spoilers clearly flagged; never fabricate storylines — report what is
confirmed (official releases, episode listings, cast interviews) and label rumours as rumours.
No ITV stills, cast photos or show logos anywhere on the site; brand art is original.
